# 测试分层与保留范围

本文维护自动化测试的分层、收录入口和当前保留范围。按改动选择验证的规则见[测试设计与验收](../agents/testing.md)，各期行为与现场验收要求见对应[规格](../INDEX.md#权威来源与适用范围)，实际执行范围以根 [justfile](../../justfile) 为准。

## 分层合同

| 层 | 目录 | 收录入口 | 资源边界 |
| --- | --- | --- | --- |
| core | `tests/core/` | `just test core`，由 `just gate-core` 收录 | 只用进程内替身，不启动数据库、子进程或真实服务，不占固定端口或共享目录；必须可在多个 worktree 并发运行，秒级完成 |
| full | `tests/cli/` | `just test tests/cli`，由 `just gate-full` 收录 | 每个测试文件自行启动隔离 Docker PostgreSQL（随机端口，`postgres:18-alpine`），使用临时归档目录和真实 CLI 子进程；浏览器能力一律使用项目接口 fake，见 `tests/helpers/` |

两层都不连接 Chrome、Extension 或 Grok。full 层中直接调用 Application 的 S1 测试也放在 `tests/cli/`，因为它们依赖真实 DB 与文件。

## 当前保留范围

2026-11-22 精简后，core 有 4 个文件、10 个用例，full 有 11 个文件、33 个用例。

core 只保留核心规则的代表性单元测试：

- Saved 第一页只读检查不展开详情；认证或限流阻挡不重试；临时失败只重试一次；连接错误中隐藏 Extension token。
- 配置默认值：唯一的 Saved 来源和默认请求间隔。
- Post 身份：详情身份必须与目标一致；图片取根 `key`；视频取最高画质且畸形高清候选不降级；非法 Post ID 在连接浏览器前就被拒绝。
- 共享请求调度：首个请求直接发出，之后按采样间隔等待。

full 覆盖各命令主流程，以及必须真实接线才能证明的核心规则：

| 命令或规则 | 保留的测试 |
| --- | --- |
| `db init`、`status` | 建表与重复初始化；status 只读 DB；schema 的 Post 主键与同 Post 摘要唯一约束（真实 DB 约束） |
| `save post` 与媒体保存 | 图片完整保存并通过 verify；真实 CLI 重复保存时复用版本，详情失败不丢失已有版本；来源变化时同摘要复用、不同摘要另存版本；文件头错误在两次有界传输后拒绝；PNG 声明的 JPEG 与原始 MP4 Data URL 长度这两种已知远端元数据偏差 |
| 发布与恢复 | 正式文件冲突时不覆盖并保留意图；真实进程在正式文件发布后被杀，重启后按文件与 DB 事实恢复；已结清归档在文件缺失时直接跳过 |
| `save first-page` | 串行处理、普通失败继续、阻挡后后续成员不预建；停止时退出 130 并保留未处理计数 |
| `retry` | 固定初始集合并逐项保存；混合 save/archive 目标串行接续；两个真实进程争用执行器锁 |
| `archive post` | 新下载绑定精确版本后归档结清；发送前停止，下次先 GET 核对；发送前丢锁不发 DELETE；未知 DELETE 响应不重发；文件冲突不 DELETE；结清提交实际成功但丢回执；在途 DELETE 首次 SIGINT 收集响应并退出 130 |
| `archive saved` | 两轮归档后合法空页完成；去重与 No Progress；旧移除事实的本地结清不算进展；真实 CLI 输出、历史摘要与 status 分开展示；空页遗留和 No Progress 均返回非零 |
| `verify`、CLI | verify 核验通过；文件缺失、内容变化和更换归档目录时只报告、不改写事实；参数或配置错误退出 2 |

不再维护以下测试类别：边界值与异常输入组合、各类响应形状的穷举矩阵、单个故障点注入（清理失败、关闭超时、权限错误、提交失回执的其余窗口）、计时与期限细节、重复验证同一规则的参数化变体、跨层重复，以及测试替身自身的行为。各期规格 Testing Decisions 中的自动化验收矩阵记录的是交付当时的验收范围，不再全部作为回归测试维护。

产品行为合同不随测试删减而改变，完整门禁通过仅证明上述保留范围。
